Услуги и цены

У каждой услуги своя цена. Цену пишите как хотите показать на сайте, например «от 3 000 ₽» или «1 500 ₽». Пустая цена — на сайте будет «цену уточняйте». Услуги появятся в прайсе, в списке «Что делаем» и в форме записи.

Первые три фото — на главном экране, все фото — в галерее. Порядок меняется стрелками. Новые фото сразу загружаются в репозиторий, на сайте появятся после «Сохранить на сайт».

Подключение к GitHub не подключено

Нужно один раз, чтобы кнопка «Сохранить на сайт» работала. Токен хранится только в этом браузере.

Как получить токен
  1. Откройте GitHub → Fine-grained tokens.
  2. Repository access: «Only select repositories» → sochi-centr.
  3. Permissions → Repository → Contents: Read and write. Создайте токен и вставьте ниже.
