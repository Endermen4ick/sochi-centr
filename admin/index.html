Заявки в Telegram не настроено

Заявки с кнопки «Записаться» приходят в Telegram от вашего бота: имя, телефон, услуга, день, время, способ связи и комментарий.

Как подключить (2 минуты)
  1. В Telegram откройте @BotFather, отправьте /newbot, придумайте имя. Скопируйте токен вида 123456:ABC… и вставьте ниже.
  2. Откройте своего нового бота и нажмите «Start» (или добавьте бота в группу мастеров и напишите там любое сообщение).
  3. Нажмите «Найти чаты» и выберите нужный — ID подставится сам. Можно указать несколько ID через запятую.
  4. Нажмите «Тестовая заявка», потом «Сохранить на сайт».

Контакты и часы работы

Запись: услуги и время

Список услуг в форме записи — по одной на строке. Время — с какого по какое и шаг в минутах.

Рейтинг и отзывы с Яндекс Карт

Окно отзывов Яндекса на сайте обновляется само. Цифры и короткие пересказы ниже показываются в блоке «Отзывы» — сверьте их с карточкой на Яндекс Картах и поправьте при необходимости.

Сохранение на GitHub не подключено

Кнопка «Сохранить на сайт» записывает настройки в файл config.json репозитория. Сайт обновится через 1–2 минуты. Нужен токен GitHub — вводится один раз и хранится только в этом браузере.

Как получить токен
  1. Откройте GitHub → Fine-grained tokens.
  2. Repository access: «Only select repositories» → этот репозиторий.
  3. Permissions → Repository → Contents: Read and write. Создайте токен и вставьте ниже.
